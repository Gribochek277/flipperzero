probe: submit with \\r\\n (works on BOTH CLIs) — Flipper CLI detection was dead
Root cause of the silent probe: the Flipper shell executes on CR and
IGNORES LF, while the Marauder CLI reads readStringUntil('\n') and trims
CR. probeMarauderPort sent a bare \n -> on the Flipper side the command
was echoed but never executed, so flipperCli was never detectable (the
probe had only been exercised against Marauder). Fix:
- probe sends command + \r\n (superset: runs on both CLIs)
- isFlipper uses includes('>: ') (a leftover prompt may be followed by
  the echoed command — the end-anchored regex missed that)
- FAKE_FLIPPER in test-marauder-bridge is now CR-only faithful (LF
  dropped) — the old fake accepted \n and masked the regression
